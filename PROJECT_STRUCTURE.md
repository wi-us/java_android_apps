## Разрешения Android (Permissions)

Приложение запрашивает следующие разрешения в файле AndroidManifest.xml:

| Разрешение | Тип | Описание |
|------------|-----|----------|
| INTERNET | Обычное | Доступ к сети Интернет. Требуется для всех HTTP-запросов к серверу и загрузки изображений. Предоставляется автоматически при установке |
| ACCESS_COARSE_LOCATION | Опасное | Определение приблизительного местоположения (по Wi-Fi, сотовым вышкам). Используется как fallback, если точная геолокация недоступна |
| ACCESS_FINE_LOCATION | Опасное | Определение точного местоположения (по GPS). Используется для центрирования карты на текущей позиции пользователя |

### Когда запрашиваются разрешения

INTERNET:
— Предоставляется автоматически при установке
— Не требует подтверждения пользователя

ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION:
— Запрашивается при открытии экрана MapPickerActivity
— Пользователь видит системный диалог с запросом
— Если разрешено — карта центрируется на текущей позиции
— Если отклонено — карта открывается на позиции по умолчанию

### Дополнительные настройки в манифесте

| Атрибут | Значение | Описание |
|---------|----------|----------|
| android:usesCleartextTraffic | true | Разрешает HTTP-соединения (не HTTPS). Требуется для подключения к тестовому серверу по IP-адресу |
| android:name | .ShopExamApp | Указывает кастомный класс Application, который сбрасывает состояние 18+ при запуске |

## Серверная часть (exam_server/)

### Структура сервера

exam_server/

    requirements.txt              — Зависимости Python
    README.md                     — Документация сервера
    api/                          — Дополнительные API-модули
        auth_routes.py            — Маршруты авторизации
        token_schema.py           — Схема JWT-токена
        routers/                  — Дополнительные роутеры
    static/                       — Статические файлы админки
        style.css                 — Стили админ-панели
        script.js                 — JavaScript админ-панели

| Файл | Описание |

## База данных (shop.db)

SQLite-база данных, содержащая 15 таблиц:

### Справочные таблицы
— role — роли пользователей (admin, customer)
— status — статусы товаров и заказов
— age_rating — возрастные рейтинги (0+, 6+, 12+, 18+)
— language — языки изданий
— genre — жанры игр

### Таблицы пользователей
— user — пользователи системы
— address — адреса доставки

### Таблицы товаров
— game — игры (названия, характеристики)
— game_variant — варианты изданий (цена, описание, статус)
— variant_image — изображения товаров
— game_genre — связь игр и жанров (M:N)

### Таблицы заказов
— cart — корзина пользователя
— cart_item — позиции в корзине
— order — заказы
— order_item — позиции заказа

## Как запустить проект

### 1. Сервер (FastAPI)

cd exam_server
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8003 --reload

### 2. Android-приложение

1. Открыть проект в Android Studio
2. В файле ApiClient.java указать IP-адрес сервера:
   private static final String BASE_URL = "http://YOUR_SERVER_IP:8003/";
3. Собрать и запустить на устройстве/эмуляторе
