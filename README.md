# Платформа для онлайн-курсов

## Испольуемые библиотеки
**Импортируемые:**
* FastAPI
* Pydantic
* peewee
* AuthX
* uvicorn
**Встроенные**
* datetime
* logging
* typing
* json
* hashlib

## Описание
Серверная часть для платформы онлайн-курсов. Функционал:
* Авторизация
* Функционал взависимости от роли
* Просмотр всех курсов
* Просмотр данных пользователя
* Просмотр курсов на которые подписан пользователь
* Запись на курсы
* Преподаватель может и редактировать добавлять курсы
* Просмотр курсов на которые подписан пользователь
* Система скидок

## Система скидок
Покупка 1 курса = скидка 5% на последующие покупки
С каждым курсом скидка растёт на 5% вплоть до 50%

## Баланс
Изначально баланс любого пользователя = 0
у администратора wi-us баланс = 122923123
Добавить баланс пользователя можно при помощи PUT запроса на путь /api/user, используя аккаунт администратора

## Роли
**Администратор**
Доступ ко всему функционалу

**Преподаватель**
Просмотр списка курсов
Добавление новых курсов
Редактирование собственных курсов
Получение списка студентов своего курса
Запись на курсы
Получение списка своих курсов

**Студент**
Просмотр списка курсов
Запись на курсы
Получение списка своих курсов

**Неавторизованный пользователь**
Просмотр списка курсов

## Безопасность
**Авторизация**
Авторизация реализована при помощи Cookie
Нужно передать логин и пароль через Query параметры по пути /api/login
После пароль хэшируется и данные сравниваются с теми, что в базе данных
Если такой всё совпадает, то пользователь получает свою печеньку

**Аутентификация**
Перед началом работы метода запроса в БД проверяется доступ пользователя к выбранному методу:
1. Производится проверка печеньки с заголовком "access_token" и токеном
2. Чтение токена и проверка его времени жизни
3. Получение основных данных пользователя из БД и создание новой модели, содержащей необходимые поля для дальнейших манипуляций и быстрой проверки данных пользовыателя без необходимости дополнительно получать о нём данные
4. Сверка роли пользователя с требуемой

## Валидация
Данные валидируются при помощи библиотеки Pydantic
Модели находятся в schemas.py
