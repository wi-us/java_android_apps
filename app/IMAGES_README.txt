Куда загружать картинки для рецептов
=====================================

Папка: app/src/main/res/drawable/

Фото блюда (готовое блюдо) — одно на рецепт:
  recipe_1_dish, recipe_2_dish, ... recipe_9_dish
  (Пирог из тыквы, Жареный хвост краба, ... Хлеб)

Иконки у ингредиентов (маленькие, в стиле игры):
  Сейчас в проекте уже есть векторные иконки:
  - WoW: ing_wow_1, ing_wow_2, ing_wow_3, ing_wow_4
  - Potion Crafter: ing_potion_1 .. ing_potion_4
  - Minecraft: ing_minecraft_1 .. ing_minecraft_4

  Их можно заменить своими картинками (например в стиле игр:
  WoW — фэнтези-иконки еды/трофеев, Potion Craft — травы/зелья,
  Minecraft — пиксельные 16x16). Имена файлов — те же (без расширения).

Если файла нет — для фото блюда показывается плейсхолдер; для иконки ингредиента — пусто.
